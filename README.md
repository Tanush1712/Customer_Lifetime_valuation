# Customer Lifetime Value Dashboard

Interactive Streamlit dashboard for the online retail customer lifetime value project.

## Run locally

1. Create and activate a Python virtual environment.
2. Install dependencies: `pip install -r requirements.txt`
3. Start the app: `streamlit run app.py`

The dashboard reads `data/clean/df_clean.csv` and provides date/country filtering, revenue and customer metrics, customer segments, value mapping, drill-down metrics, and a CSV export.
